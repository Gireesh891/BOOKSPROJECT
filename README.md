BOOKSPROJECT

A web application designed to manage and track books. This project allows users to add, view, and organize their book collections efficiently.

🚀 Features

Add Books: Users can add new books to their collection.

View Books: Browse and view details of added books.

Organize Books: Categorize books for better organization.

Responsive Design: Optimized for both desktop and mobile devices.

🛠️ Technologies Used

Backend: Node.js

Database: MongoDB

Routing: Express.js

Environment Variables: dotenv

Templating Engine: EJS

Styling: CSS
